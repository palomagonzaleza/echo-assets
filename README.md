# Echo — Brand assets

Logos con URL pública para usar en mails (release notes) y documentos.

**Página:** https://palomagonzaleza.github.io/echo-assets/

## Para mails

Usá el **PNG**. Los clientes de correo no renderizan SVG, y Gmail bloquea las imágenes en `base64`.

```html
<img src="https://palomagonzaleza.github.io/echo-assets/logos/kforce-echo-logo.png"
     alt="Echo by Kforce" width="235" style="display:block;height:30px;width:auto;border:0">
```
